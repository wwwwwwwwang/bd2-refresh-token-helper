# 文档变更记录

## 2026-08-18

- 发布 `v1.0.2`：捕获 Refresh Token 后不再自动清理网页登录数据或跳回首页，用户可继续操作当前网页。
- 在网页上方增加“请开启加速后登录”常驻提示，帮助用户在登录前完成网络准备。
- 发布 `v1.0.1`：使用用户提供的图片补齐传统与自适应 Android 启动图标。
- 增加可重复执行的 launcher icon 生成脚本和资源完整性测试。
- Release 工具增加临时 API 错误有限重试，并支持对已有 Tag 手动恢复发布。

## 2026-08-17

- 建立独立公开仓库文档结构。
- 增加隐私说明、安全架构和正式签名发布流程。
- 规划首个正式版本 `v1.0.0`，由 GitHub Actions 发布 APK 和 SHA-256。
